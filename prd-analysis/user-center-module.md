## 1. 求助者中心功能清單（F14-F17）

### F14: 幫助檔案

| 屬性 | 詳情 |
|------|------|
| **優先級** | P1 |
| **功能定位** | 求助者的歷史記錄中心，用於回顧和統計 |

**功能詳述：**
- **自動記錄生成**：每次求助自動生成記錄
  - 記錄字段：時間、類型（AI/人工）、志願者（匿名）、用時、評價
- **AI對話回顧**：可查看歷史AI對話完整內容
- **數據統計面板**：
  - 本月求助次數統計
  - AI解決率（AI成功處理/總求助數）
  - 最常用功能排行

**數據關聯：**
- 關聯表：`help_requests`（求助記錄主表）
- 篩選條件：`seeker_id = 當前用戶ID`
- 排序：按 `created_at` 倒序

### F15: 安心積分

| 屬性 | 詳情 |
|------|------|
| **優先級** | P2（MVP可延後） |
| **功能定位** | 用戶留存激勵系統，培養使用習慣 |

**積分規則：**

| 行爲 | 積分 |
|------|------|
| 連續使用1天 | +1 |
| 連續使用7天 | +10（額外獎勵） |
| 連續使用30天 | +50（月度獎勵） |

**積分用途：**
- 兌換緊急求助優先權（排隊插隊）
- 兌換生日AI定製祝福

**實現要點：**
- 需要 `user_points` 表或擴展 `users` 表字段
- 連續天數計算邏輯：每日首次打開App即算"使用"
- 斷籤後重新從Day1計算

### F16: 常用志願者

| 屬性 | 詳情 |
|------|------|
| **優先級** | P1 |
| **功能定位** | 建立長期互助關係，提升匹配滿意度 |

**功能流程：**
1. **添加條件**：雙方互評高分（≥4星）後，系統提示"是否加爲常用志願者"
2. **匹配權重加成**：常用志願者在匹配算法中獲得額外權重（w5親密度係數提升）
3. **重逢驚喜**：再次連接時顯示"你們已經是第N次合作了！"

**數據設計：**
```sql
-- 常用志願者關係表
favorite_volunteers (
  id UUID PK,
  seeker_id UUID FK → users,
  volunteer_id UUID FK → users,
  cooperation_count INT DEFAULT 1,  -- 合作次數
  created_at TIMESTAMPTZ,
  UNIQUE(seeker_id, volunteer_id)
)
```

| **功能定位** | 核心無障礙體驗配置 |

| **障礙類型** | 視障 / 聽障 / 肢體障礙 / 老年人 / 臨時困難 / 其他 | 多選，影響UI默認配置 |

## 2. 志願者中心功能清單（F18-F23）

### F18: 等級與積分系統

| 屬性 | 詳情 |
|------|------|
| **優先級** | P1 |
| **功能定位** | 志願者成長激勵核心系統 |

#### 等級體系表

| 等級 | 名稱 | 所需積分 | 解鎖權益 |
|------|------|---------|---------|
| Lv1 | 青苗 🌱 | 0 | 基礎幫助功能 |
| Lv2 | 嫩芽 🌿 | 100 | 異步任務領取 |
| Lv3 | 新葉 🍀 | 300 | 技能標籤展示 |
| Lv4 | 綠蔭 🌳 | 800 | 專屬客服 + 優先匹配 |
| Lv5 | 暖陽 ☀️ | 2000 | 線下活動邀請 |
| Lv6 | 星辰 ⭐ | 5000 | 公益時數證書 + 積分商城 |
| Lv7 | 燈塔 🏠 | 10000 | 平臺認證 + 簡歷背書 + 年度善意報告 |

#### 積分規則明細

| 行爲 | 積分 | 說明 |
|------|------|------|
| 完成一次實時幫助 | +10 | 語音/視頻通話完成 |
| 完成一次異步幫助 | +5 | 異步任務完成 |
| 獲得5星好評 | +3 | 額外獎勵，每次幫助最多+3 |
| 連續7天幫助 | +20 | 連續7天每天都有完成幫助 |
| 完成每日小任務 | +2 | 如：分享App、完善資料等 |
| 被舉報有效 | -50 | 懲罰機制 |

#### 積分計算邏輯

```
總積分 = Σ(正向積分) - Σ(懲罰積分)

等級判定：
- 0-99 → Lv1
- 100-299 → Lv2
- 300-799 → Lv3
- 800-1999 → Lv4
- 2000-4999 → Lv5
- 5000-9999 → Lv6
- ≥10000 → Lv7

升級時觸發：推送通知 + 徽章授予 + 權益解鎖
```

### F22: 異步任務隊列

| 屬性 | 詳情 |
|------|------|
| **優先級** | P1 |
| **功能定位** | 志願者處理非緊急求助的工作臺 |

**功能流程：**
1. 志願者進入"異步任務"頁面
2. 可瀏覽待處理的異步求助列表
3. 支持篩選：按技能標籤、按距離、按時間
4. 領取任務 → 處理（語音/文字/標註圖片）→ 提交回復

**數據關聯：**
- 主表：`async_tasks`
- 狀態流轉：pending → claimed → completed / expired
- 超時機制：24小時未處理自動重新分配

## 3. 等級與積分系統設計彙總

### 3.1 完整等級體系表

| 等級 | 名稱 | 積分區間 | 權益差異 |
|------|------|---------|---------|
| Lv1 | 青苗 🌱 | 0-99 | 僅實時幫助 |
| Lv2 | 嫩芽 🌿 | 100-299 | +異步任務 |
| Lv3 | 新葉 🍀 | 300-799 | +技能展示 |
| Lv4 | 綠蔭 🌳 | 800-1999 | +專屬客服 |
| Lv5 | 暖陽 ☀️ | 2000-4999 | +線下活動 |
| Lv6 | 星辰 ⭐ | 5000-9999 | +公益證書 |
| Lv7 | 燈塔 🏠 | ≥10000 | +平臺認證 |

### 3.2 積分規則明細彙總

| 行爲類型 | 積分變化 | 觸發條件 | 限制 |
|---------|---------|---------|------|
| 實時幫助完成 | +10 | 通話正常結束 | 無 |
| 異步幫助完成 | +5 | 任務標記完成 | 無 |
| 五星好評 | +3 | 獲得5星評價 | 每次幫助最多1次 |
| 連續7天幫助 | +20 | 連續7天有完成記錄 | 每7天週期1次 |
| 每日任務 | +2 | 完成指定任務 | 每日1次 |
| 有效舉報 | -50 | 被確認違規 | 無上限 |

### 3.3 積分計算邏輯

```
積分流水計算：
1. 實時觸發：幫助完成時立即計算基礎積分
2. 評價觸發：收到好評時追加獎勵積分
3. 定時任務：每日0點檢查連續幫助天數
4. 懲罰觸發：舉報審覈通過後扣除

等級晉升檢查：
- 每次積分變動後檢查是否滿足升級條件
- 升級時：推送通知 + 解鎖權益 + 授予等級徽章
- 降級策略：本系統不考慮降級（積分只增不減，除非懲罰）
```

## 4. 用戶數據結構

### 4.1 求助者角色字段需求

**基礎信息（users表）：**
| 字段 | 類型 | 說明 |
|------|------|------|
| id | UUID | 主鍵 |
| phone | TEXT | 手機號，唯一 |
| name | TEXT | 暱稱 |
| avatar_url | TEXT | 頭像URL |
| role | TEXT[] | ['seeker'] 或 ['seeker', 'volunteer'] |
| disability_type | TEXT[] | 障礙類型數組 |
| preferences | JSONB | 無障礙偏好設置 |
| created_at | TIMESTAMPTZ | 註冊時間 |

**擴展數據：**
| 字段 | 來源表 | 說明 |
|------|--------|------|
| 安心積分 | users.points | 可擴展字段 |
| 常用志願者 | favorite_volunteers表 | 關聯查詢 |
| 求助歷史 | help_requests表 | seeker_id關聯 |
| 緊急聯繫人 | emergency_contacts表 | user_id關聯 |

### 4.2 志願者角色字段需求

**基礎信息（users表）：**
- 同求助者基礎字段
- role 包含 'volunteer'

**志願者專屬（volunteer_profiles表）：**
| 字段 | 類型 | 說明 |
|------|------|------|
| user_id | UUID FK | 關聯users表 |
| skills | TEXT[] | 技能標籤數組 |
| level | INT | 當前等級 1-7 |
| points | INT | 當前積分 |
| credit_score | DECIMAL | 信譽分 0-5 |
| is_verified | BOOLEAN | 是否實名認證 |
| available_schedule | JSONB | 排班設置 |
| is_online | BOOLEAN | 在線狀態 |
| location | GEOGRAPHY | 位置座標 |

**擴展數據：**
| 字段 | 來源表 | 說明 |
|------|--------|------|
| 徽章 | badges表 | user_id關聯 |
| 積分流水 | point_transactions表 | user_id關聯 |
| 幫助歷史 | help_requests表 | volunteer_id關聯 |
| 異步任務 | async_tasks表 | volunteer_id關聯 |

### 4.3 關聯關係圖

```
users (用戶基礎表)
├── 求助者角色 ──┬── favorite_volunteers (常用志願者)
│               ├── help_requests.seeker_id (求助記錄)
│               └── emergency_contacts (緊急聯繫人)
│
└── 志願者角色 ──┬── volunteer_profiles (志願者檔案)
                ├── badges (徽章)
                ├── point_transactions (積分流水)
                ├── help_requests.volunteer_id (幫助記錄)
                └── async_tasks (異步任務)
```

## 6. 關鍵實現建議

### 6.1 數據庫索引建議

```sql
-- 志願者匹配查詢優化
CREATE INDEX idx_volunteer_profiles_online ON volunteer_profiles(is_online, level);
CREATE INDEX idx_volunteer_profiles_location ON volunteer_profiles USING GIST(location);

-- 積分流水查詢優化
CREATE INDEX idx_point_transactions_user_id ON point_transactions(user_id, created_at DESC);

-- 幫助歷史查詢優化
CREATE INDEX idx_help_requests_seeker ON help_requests(seeker_id, created_at DESC);
CREATE INDEX idx_help_requests_volunteer ON help_requests(volunteer_id, created_at DESC);
```

### 6.2 接口設計要點

| 接口 | 用途 | 關鍵字段 |
|------|------|---------|
| GET /api/seeker/profile | 獲取求助者檔案 | 基本信息 + 統計 |
| GET /api/seeker/history | 求助歷史 | 分頁 + 篩選 |
| PUT /api/seeker/preferences | 更新偏好設置 | JSONB全量更新 |
| GET /api/volunteer/profile | 獲取志願者檔案 | 等級 + 積分 + 技能 |
| GET /api/volunteer/points | 積分流水 | 分頁 |
| POST /api/volunteer/skills | 更新技能標籤 | 數組覆蓋 |
| GET /api/volunteer/async-tasks | 異步任務列表 | 篩選 + 分頁 |
| POST /api/volunteer/async-tasks/:id/claim | 領取任務 | 狀態變更 |

### 6.3 風險提示

1. **積分併發問題**：多人同時完成幫助時，積分更新需加鎖或使用原子操作
2. **等級權益控制**：Lv2+才能領取異步任務，接口需做權限校驗
3. **隱私保護**：常用志願者關係中，志願者對求助者是匿名的
4. **數據一致性**：用戶刪除賬號時，需處理關聯的積分、徽章、歷史記錄
