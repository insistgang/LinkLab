## 1. 求助者中心功能清单（F14-F17）

### F14: 帮助档案

| 属性 | 详情 |
|------|------|
| **优先级** | P1 |
| **功能定位** | 求助者的历史记录中心，用于回顾和统计 |

**功能详述：**
- **自动记录生成**：每次求助自动生成记录
  - 记录字段：时间、类型（AI/人工）、志愿者（匿名）、用时、评价
- **AI对话回顾**：可查看历史AI对话完整内容
- **数据统计面板**：
  - 本月求助次数统计
  - AI解决率（AI成功处理/总求助数）
  - 最常用功能排行

**数据关联：**
- 关联表：`help_requests`（求助记录主表）
- 筛选条件：`seeker_id = 当前用户ID`
- 排序：按 `created_at` 倒序

### F15: 安心积分

| 属性 | 详情 |
|------|------|
| **优先级** | P2（MVP可延后） |
| **功能定位** | 用户留存激励系统，培养使用习惯 |

**积分规则：**

| 行为 | 积分 |
|------|------|
| 连续使用1天 | +1 |
| 连续使用7天 | +10（额外奖励） |
| 连续使用30天 | +50（月度奖励） |

**积分用途：**
- 兑换紧急求助优先权（排队插队）
- 兑换生日AI定制祝福

**实现要点：**
- 需要 `user_points` 表或扩展 `users` 表字段
- 连续天数计算逻辑：每日首次打开App即算"使用"
- 断签后重新从Day1计算

### F16: 常用志愿者

| 属性 | 详情 |
|------|------|
| **优先级** | P1 |
| **功能定位** | 建立长期互助关系，提升匹配满意度 |

**功能流程：**
1. **添加条件**：双方互评高分（≥4星）后，系统提示"是否加为常用志愿者"
2. **匹配权重加成**：常用志愿者在匹配算法中获得额外权重（w5亲密度系数提升）
3. **重逢惊喜**：再次连接时显示"你们已经是第N次合作了！"

**数据设计：**
```sql
-- 常用志愿者关系表
favorite_volunteers (
  id UUID PK,
  seeker_id UUID FK → users,
  volunteer_id UUID FK → users,
  cooperation_count INT DEFAULT 1,  -- 合作次数
  created_at TIMESTAMPTZ,
  UNIQUE(seeker_id, volunteer_id)
)
```

## 2. 志愿者中心功能清单（F18-F23）

### F18: 等级与积分系统

| 属性 | 详情 |
|------|------|
| **优先级** | P1 |
| **功能定位** | 志愿者成长激励核心系统 |

#### 等级体系表

| 等级 | 名称 | 所需积分 | 解锁权益 |
|------|------|---------|---------|
| Lv1 | 青苗 🌱 | 0 | 基础帮助功能 |
| Lv2 | 嫩芽 🌿 | 100 | 异步任务领取 |
| Lv3 | 新叶 🍀 | 300 | 技能标签展示 |
| Lv4 | 绿荫 🌳 | 800 | 专属客服 + 优先匹配 |
| Lv5 | 暖阳 ☀️ | 2000 | 线下活动邀请 |
| Lv6 | 星辰 ⭐ | 5000 | 公益时数证书 + 积分商城 |
| Lv7 | 灯塔 🏠 | 10000 | 平台认证 + 简历背书 + 年度善意报告 |

#### 积分规则明细

| 行为 | 积分 | 说明 |
|------|------|------|
| 完成一次实时帮助 | +10 | 语音/视频通话完成 |
| 完成一次异步帮助 | +5 | 异步任务完成 |
| 获得5星好评 | +3 | 额外奖励，每次帮助最多+3 |
| 连续7天帮助 | +20 | 连续7天每天都有完成帮助 |
| 完成每日小任务 | +2 | 如：分享App、完善资料等 |
| 被举报有效 | -50 | 惩罚机制 |

#### 积分计算逻辑

```
总积分 = Σ(正向积分) - Σ(惩罚积分)

等级判定：
- 0-99 → Lv1
- 100-299 → Lv2
- 300-799 → Lv3
- 800-1999 → Lv4
- 2000-4999 → Lv5
- 5000-9999 → Lv6
- ≥10000 → Lv7

升级时触发：推送通知 + 徽章授予 + 权益解锁
```

### F22: 异步任务队列

| 属性 | 详情 |
|------|------|
| **优先级** | P1 |
| **功能定位** | 志愿者处理非紧急求助的工作台 |

**功能流程：**
1. 志愿者进入"异步任务"页面

## 3. 等级与积分系统设计汇总

### 3.1 完整等级体系表

| 等级 | 名称 | 积分区间 | 权益差异 |
|------|------|---------|---------|
| Lv1 | 青苗 🌱 | 0-99 | 仅实时帮助 |
| Lv2 | 嫩芽 🌿 | 100-299 | +异步任务 |
| Lv3 | 新叶 🍀 | 300-799 | +技能展示 |
| Lv4 | 绿荫 🌳 | 800-1999 | +专属客服 |
| Lv5 | 暖阳 ☀️ | 2000-4999 | +线下活动 |
| Lv6 | 星辰 ⭐ | 5000-9999 | +公益证书 |
| Lv7 | 灯塔 🏠 | ≥10000 | +平台认证 |

### 3.2 积分规则明细汇总

| 行为类型 | 积分变化 | 触发条件 | 限制 |
|---------|---------|---------|------|
| 实时帮助完成 | +10 | 通话正常结束 | 无 |
| 异步帮助完成 | +5 | 任务标记完成 | 无 |
| 五星好评 | +3 | 获得5星评价 | 每次帮助最多1次 |
| 连续7天帮助 | +20 | 连续7天有完成记录 | 每7天周期1次 |
| 每日任务 | +2 | 完成指定任务 | 每日1次 |
| 有效举报 | -50 | 被确认违规 | 无上限 |

### 3.3 积分计算逻辑

```
积分流水计算：
1. 实时触发：帮助完成时立即计算基础积分
2. 评价触发：收到好评时追加奖励积分
3. 定时任务：每日0点检查连续帮助天数
4. 惩罚触发：举报审核通过后扣除

等级晋升检查：
- 每次积分变动后检查是否满足升级条件
- 升级时：推送通知 + 解锁权益 + 授予等级徽章
- 降级策略：本系统不考虑降级（积分只增不减，除非惩罚）
```

## 6. 关键实现建议

### 6.1 数据库索引建议

```sql
-- 志愿者匹配查询优化
CREATE INDEX idx_volunteer_profiles_online ON volunteer_profiles(is_online, level);
CREATE INDEX idx_volunteer_profiles_location ON volunteer_profiles USING GIST(location);

-- 积分流水查询优化
CREATE INDEX idx_point_transactions_user_id ON point_transactions(user_id, created_at DESC);

-- 帮助历史查询优化
CREATE INDEX idx_help_requests_seeker ON help_requests(seeker_id, created_at DESC);
CREATE INDEX idx_help_requests_volunteer ON help_requests(volunteer_id, created_at DESC);
```

### 6.2 接口设计要点

| 接口 | 用途 | 关键字段 |
|------|------|---------|
| GET /api/seeker/profile | 获取求助者档案 | 基本信息 + 统计 |
| GET /api/seeker/history | 求助历史 | 分页 + 筛选 |
| PUT /api/seeker/preferences | 更新偏好设置 | JSONB全量更新 |
| GET /api/volunteer/profile | 获取志愿者档案 | 等级 + 积分 + 技能 |
| GET /api/volunteer/points | 积分流水 | 分页 |
| POST /api/volunteer/skills | 更新技能标签 | 数组覆盖 |
| GET /api/volunteer/async-tasks | 异步任务列表 | 筛选 + 分页 |
| POST /api/volunteer/async-tasks/:id/claim | 领取任务 | 状态变更 |

### 6.3 风险提示

1. **积分并发问题**：多人同时完成帮助时，积分更新需加锁或使用原子操作
2. **等级权益控制**：Lv2+才能领取异步任务，接口需做权限校验
3. **隐私保护**：常用志愿者关系中，志愿者对求助者是匿名的
4. **数据一致性**：用户删除账号时，需处理关联的积分、徽章、历史记录
