## 0. 一句話定義

**LinkAble 是一套基於邊緣智能的無障礙輔助通行感知系統，面向視障與行動不便人羣。**

它用 Jetson 邊緣設備和攝像頭感知人行無障礙空間中的盲道佔用、臺階、坡道和路面障礙，把視覺檢測結果壓縮成簡短、明確、可執行的語音提示，幫助用戶判斷"眼前這一步怎麼安全通過"。

一句話對比：

> 無人駕駛讓車看懂路，LinkAble 讓弱勢行人聽懂路。

當前研電賽版本重點驗證：

```
視覺感知 → 事件理解 → 本地語音提示 → 結構化記錄
```

## 1. 應用價值

### 1.1 填補"最後幾米"的空白

現有導航 App 解決"從 A 走到 B"，盲杖只能探測 1 米內有無障礙物，均無法回答"眼前這一步是什麼、怎麼應對"。LinkAble 填補此空白：識別障礙類型，給出可執行提示。

### 1.2 讓無障礙環境問題變可見

結構化事件記錄（時間、位置、類型、置信度）天然形成無障礙環境巡檢數據，可沉澱爲校園/社區無障礙治理的量化依據。

### 1.3 低成本可部署

單攝像頭 + Jetson 邊緣推理，無需改造基礎設施，支持可穿戴、手持巡檢、固定點位三種部署形態，共享同一套感知、事件和播報代碼。

### 1.4 安全邊界聲明

系統定位爲"輔助提示"，不替代盲杖、導盲犬或用戶自主判斷，不直接控制用戶行動。

## 4. 系統架構

### 主鏈路

```
攝像頭/圖片/視頻輸入
  → YOLO 檢測（yolo11n.pt）
  → 事件聚合與去抖（EventBuilder）
  → 模板化中文提示（semantics.py）
  → 本地音頻播報（audio.py / MiniMax TTS）
  → 結構化事件記錄（publisher.py）
```

### 核心原則

- 端側優先，不依賴雲端才能播報
- 音頻優先使用本地緩存
- 雲端和 App 是增強，不是主鏈路

### 推薦模塊

| 模塊 | 職責 |
|---|---|
| `detector.py` | YOLOv11 推理，P0 類別過濾 |
| `event_builder.py` | 連續幀去抖、冷卻控制、優先級排序 |
| `semantics.py` | 事件轉模板化中文提示 |
| `audio.py` | 本地 mp3 播報、失敗降級 |
| `pipeline.py` | 串聯完整主鏈路 |
| `publisher.py` | 可選 HTTP 上報結構化事件 |
| `usb_demo.py` | 主演示入口 |

### 部署形態

| 形態 | 當前定位 |
|---|---|
| 胸前/肩帶式短距離佩戴 | 演示形態，適合拍攝靠近障礙的視頻 |
| 手持/推車式巡檢 | 推薦主形態，適合校園無障礙環境巡檢 |
| 固定點位監測 | 備用形態，適合盲道/坡道入口固定場景 |

## 5. P0 功能範圍

### 5.1 P0 必做

| 功能 | 驗收標準 |
|---|---|
| 盲道佔用檢測（`blind_road_occupied`） | 典型場景可穩定觸發 |
| 臺階識別（`stairs`） | 能播報減速/注意提示 |
| 坡道識別（`ramp`） | 能給出坡道存在或方位提示 |
| 路面障礙檢測（`road_obstacle`） | 能觸發避讓提示 |
| 事件聚合與去抖 | 同一障礙不連續刷屏 |
| 模板化語義提示 | 輸出 <50 字中文短句，明確可執行 |
| 本地音頻播報 | 不依賴雲端即可演示 |
| 結構化事件記錄 | 含 node_id、timestamp、type、confidence |

### 5.2 P1 增強（P0 穩定後推進）

檢測結果上報 FastAPI、雲端語義增強、Flutter 展示頁、主動語音查詢、紅綠燈識別、人行橫道識別

### 5.3 P2 本期不做

志願者互助系統、多用戶併發平臺、量產級硬件外殼

| 類別 | 英文名 | 優先級 | 說明 |
|---|---|---|---|

## 7. 語音播報策略

### 默認音色

```
model = speech-2.8-hd
voice_id = presenter_female
```

### 播報原則

- 句子短，優先 <50 字
- 必須包含風險類型
- 有條件時包含距離或方向
- 避免"可能、似乎、也許"等不確定措辭
- 不連續重複播報同一障礙

### 推薦文案

```
前方盲道被佔用，請注意繞行。
前方有臺階，請減速。
右前方有障礙，請注意避讓。
前方有坡道，位於右側。
```

### 降級策略

| 問題 | 降級 |
|---|---|
| MiniMax 網絡不可用 | 使用本地緩存 mp3 |
| mp3 缺失 | 終端文字輸出 |
| 音頻設備異常 | 顯示字幕/日誌 |
| 同一事件重複觸發 | 冷卻時間內不播報 |

## 8. 數據與模型

### 數據採集目標

```
>=600 張有效圖像
```

推薦分佈：

| 場景 | 佔比 |
|---|---:|
| 盲道佔用 | 35% |
| 臺階 | 20% |
| 坡道 | 20% |
| 路面障礙 | 25% |

### 模型路線

```
yolo11n PyTorch → ONNX → TensorRT FP16
```

階段性止損：

- 自定義模型未完成時，用 COCO 代理類演示完整鏈路
- TensorRT 未完成時，用 PyTorch/Ultralytics 先證明功能閉環
- 攝像頭未恢復時，用圖片序列或視頻文件模擬移動場景

## 9. 性能與驗收指標

| 指標 | 目標 |
|---|---|
| Jetson 端推理幀率 | ≥30 FPS |
| 單幀推理延遲 | <100 ms |
| 檢測到播報響應 | <1.5 s |
| 主要場景準確率 | ≥80% |
| 同一障礙重複播報 | 冷卻時間內不重複 |
| 離線演示能力 | 雲端不可用時仍可播報 |

### 論文/答辯必須量化

- FPS、單幀推理延遲
- 檢測到播報延遲
- TTS 冷啓動與緩存命中延遲
- 典型場景識別成功率
- 數據集規模和類別分佈
- 演示場景實測記錄

## 13. 對外口徑

### 30 秒介紹

LinkAble 是一套基於邊緣智能的無障礙輔助通行感知系統。系統通過 Jetson 和攝像頭感知人行空間中的盲道佔用、臺階、坡道和路面障礙，在端側完成事件聚合和本地語音播報。相比自動駕駛關注車輛行駛，LinkAble 關注弱勢行人眼前幾米的安全通行，把視覺檢測結果轉化爲簡短、明確、可執行的語音提示。

### 展架主標題

```
從"車能自己開"到"人能安全走"
```

### 展架副標題

```
基於邊緣智能的無障礙輔助通行感知系統
```

### 核心賣點

- 面向人行無障礙空間，而非機動車道
- 單攝像頭 + Jetson 邊緣推理，低成本可部署
- 檢測結果轉語音提示，用戶可直接執行
- 支持可穿戴、手持巡檢、固定點位多種形態
- 結構化事件可沉澱爲無障礙治理數據

### 禁止說的
