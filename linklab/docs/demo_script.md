## 演示流程

### 開場 (30秒)

**講解詞**：
> "大家好，今天演示的是'共感 LinkAble'——一款爲視障、聽障及老年羣體設計的智能助殘應用。我們的核心理念是'AI+真人志願者'雙引擎，讓科技更有溫度。"

**操作**：展示應用圖標，點擊進入

---

### 第一幕：首頁與無障礙設計 (30秒)

**演示內容**：
1. 展示首頁超大按鈕設計（4個大按鈕）
2. 展示高對比度主題
3. 展示語音播報功能

**操作步驟**：
1. 展示首頁四個大按鈕
   - 文字識別（相機圖標）
   - 場景描述（眼睛圖標）
   - 顏色識別（調色板圖標）
   - 語音求助（麥克風圖標）
2. 點擊按鈕時的震動反饋
3. 語音播報："文字識別按鈕"

**講解詞**：
> "我們的設計遵循WCAG 2.1 AAA無障礙標準，所有按鈕都是48x48dp以上，支持高對比度模式和系統字體縮放。"

---

### 第二幕：藥品識別 → 轉人工 → 匹配 → 通話 (2分鐘)

**場景**：用戶需要識別藥品說明書

**操作步驟**：

1. **點擊語音求助** (2秒)
   - 點擊首頁"語音求助"大按鈕
   - 進入AI對話界面

2. **AI問候** (3秒)
   - AI播報："您好！我是您的智能助手，有什麼可以幫助您的嗎？"

3. **用戶輸入** (3秒)
   - 語音輸入："幫我看一下這個藥怎麼喫"
   - 或文字輸入

4. **AI識別回覆** (5秒)
   - 展示拍照界面
   - 使用預置藥品圖片
   - AI回覆：
     ```
     識別結果：阿司匹林腸溶片 100mg
     
     用法用量：
     • 每日一次，每次1片
     • 飯後服用
     
     ⚠️ 這是藥品，建議志願者確認
     ```

5. **請求人工** (3秒)
   - 用戶說："我想讓志願者幫我確認一下"
   - AI回覆："好的，正在爲您連接志願者..."

6. **匹配頁面** (3秒)
   - 展示匹配動畫
   - 顯示"正在尋找附近的志願者..."
   - 進度條動畫

7. **匹配成功** (2秒)
   - 展示志願者信息卡片
   - 志願者：小李（燈塔 🏠）
   - 距離：1.2km
   - 評分：4.9分

8. **通話界面** (10秒)
   - 進入通話頁面
   - 展示志願者頭像
   - 展示通話控制按鈕（靜音、揚聲器、掛斷）
   - 模擬志願者語音：
     - "您好，我是小李，讓我幫您確認這個藥品"
     - "是的，這是阿司匹林，每天一片飯後喫"

9. **結束通話** (2秒)
   - 點擊掛斷按鈕
   - 進入評價頁面

10. **評價** (3秒)
    - 選擇5星評價
    - 選擇標籤："非常有耐心"
    - 點擊提交

**講解詞**：
> "AI可以處理80%的標準化需求，但涉及藥品安全時，我們會建議轉接志願者確認。演示中匹配到了距離1.2公里的志願者小李，他有128次幫助經驗。"

---

### 第三幕：菜單識別 → AI直接回答 (1分鐘)

**場景**：用戶在餐廳需要看菜單

**操作步驟**：

1. **點擊文字識別** (2秒)
   - 點擊首頁"文字識別"按鈕

2. **拍照** (3秒)
   - 展示相機界面
   - 使用預置菜單圖片

3. **AI識別** (5秒)
   - 展示識別動畫
   - AI朗讀結果：
     ```
     識別結果：
     
     宮保雞丁 38元
     魚香肉絲 32元
     麻婆豆腐 28元
     清蒸鱸魚 58元
     ```

4. **完成** (2秒)
   - 用戶滿意
   - 返回首頁

**講解詞**：
> "對於簡單的文字識別，AI可以直接處理，快速響應用戶需求。"

---

### 第四幕：場景描述 → AI直接回答 (1分鐘)

**場景**：用戶在陌生環境需要了解周圍

**操作步驟**：

1. **點擊場景描述** (2秒)
   - 點擊首頁"場景描述"按鈕

2. **拍照** (3秒)
   - 展示相機界面
   - 使用預置場景圖片

3. **AI描述** (5秒)
   - AI描述場景：
     ```
     場景描述：
     
     前方2米有一張木桌
     右側1米有一扇門
     桌上有水杯（注意避讓）
     地面平整，可以直行
     ```

4. **完成** (2秒)
   - 用戶瞭解環境
   - 返回首頁

**講解詞**：
> "場景描述功能幫助用戶感知周圍環境，提供導航參考。"

---

### 第五幕：顏色識別 → AI直接回答 (1分鐘)

**場景**：用戶需要識別衣服顏色

**操作步驟**：

1. **點擊顏色識別** (2秒)
   - 點擊首頁"顏色識別"按鈕

2. **拍照** (3秒)
   - 展示相機界面
   - 使用預置衣服圖片

3. **AI識別** (5秒)
   - AI識別顏色：
     ```
     這件衣服是深藍色
     
     相近顏色：
     • 藏青色
     • 海軍藍
     
     搭配建議：
     適合搭配白色或淺灰色褲子
     ```

4. **完成** (2秒)
   - 用戶滿意
   - 返回首頁

**講解詞**：
> "顏色識別不僅告訴用戶顏色，還提供搭配建議。"

---

### 第六幕：SOS緊急求助 (1分鐘)

**場景**：用戶遇到緊急情況

**操作步驟**：

1. **觸發SOS** (3秒)
   - 長按或連按電源鍵3次（模擬）
   - 進入SOS緊急頁面

2. **SOS頁面** (5秒)
   - 顯示紅色警告界面
   - 顯示倒計時（5秒）
   - 顯示"正在聯繫志願者和緊急聯繫人..."
   - 顯示取消按鈕

3. **緊急匹配** (3秒)
   - 倒計時結束
   - 進入緊急匹配
   - 優先顯示最近志願者

4. **通話** (5秒)
   - 快速匹配成功
   - 進入通話
   - 志願者：張醫生
   - 模擬語音："您好，我是張醫生，收到您的緊急求助。您現在安全嗎？"

5. **結束** (2秒)
   - 掛斷通話
   - 演示結束

**講解詞**：
> "緊急情況可以連按電源鍵3次觸發SOS，系統會同時通知志願者和緊急聯繫人，優先匹配最近的志願者。"
