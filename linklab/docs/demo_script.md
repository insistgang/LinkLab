## 演示流程

### 开场 (30秒)

**讲解词**：
> "大家好，今天演示的是'共感 LinkAble'——一款为视障、听障及老年群体设计的智能助残应用。我们的核心理念是'AI+真人志愿者'双引擎，让科技更有温度。"

**操作**：展示应用图标，点击进入

---

### 第一幕：首页与无障碍设计 (30秒)

**演示内容**：
1. 展示首页超大按钮设计（4个大按钮）
2. 展示高对比度主题
3. 展示语音播报功能

**操作步骤**：
1. 展示首页四个大按钮
   - 文字识别（相机图标）
   - 场景描述（眼睛图标）
   - 颜色识别（调色板图标）
   - 语音求助（麦克风图标）
2. 点击按钮时的震动反馈
3. 语音播报："文字识别按钮"

**讲解词**：
> "我们的设计遵循WCAG 2.1 AAA无障碍标准，所有按钮都是48x48dp以上，支持高对比度模式和系统字体缩放。"

---

### 第二幕：药品识别 → 转人工 → 匹配 → 通话 (2分钟)

**场景**：用户需要识别药品说明书

**操作步骤**：

1. **点击语音求助** (2秒)
   - 点击首页"语音求助"大按钮
   - 进入AI对话界面

2. **AI问候** (3秒)
   - AI播报："您好！我是您的智能助手，有什么可以帮助您的吗？"

3. **用户输入** (3秒)
   - 语音输入："帮我看一下这个药怎么吃"
   - 或文字输入

4. **AI识别回复** (5秒)
   - 展示拍照界面
   - 使用预置药品图片
   - AI回复：
     ```
     识别结果：阿司匹林肠溶片 100mg

     用法用量：
     • 每日一次，每次1片
     • 饭后服用

     ⚠️ 这是药品，建议志愿者确认
     ```

5. **请求人工** (3秒)
   - 用户说："我想让志愿者帮我确认一下"
   - AI回复："好的，正在为您连接志愿者..."

6. **匹配页面** (3秒)
   - 展示匹配动画
   - 显示"正在寻找附近的志愿者..."
   - 进度条动画

7. **匹配成功** (2秒)
   - 展示志愿者信息卡片
   - 志愿者：小李（灯塔 🏠）
   - 距离：1.2km
   - 评分：4.9分

8. **通话界面** (10秒)
   - 进入通话页面
   - 展示志愿者头像
   - 展示通话控制按钮（静音、扬声器、挂断）
   - 模拟志愿者语音：
     - "您好，我是小李，让我帮您确认这个药品"
     - "是的，这是阿司匹林，每天一片饭后吃"

9. **结束通话** (2秒)
   - 点击挂断按钮
   - 进入评价页面

10. **评价** (3秒)
    - 选择5星评价
    - 选择标签："非常有耐心"
    - 点击提交

**讲解词**：
> "AI可以处理80%的标准化需求，但涉及药品安全时，我们会建议转接志愿者确认。演示中匹配到了距离1.2公里的志愿者小李，他有128次帮助经验。"

---

### 第三幕：菜单识别 → AI直接回答 (1分钟)

**场景**：用户在餐厅需要看菜单

**操作步骤**：

1. **点击文字识别** (2秒)
   - 点击首页"文字识别"按钮

2. **拍照** (3秒)
   - 展示相机界面
   - 使用预置菜单图片

3. **AI识别** (5秒)
   - 展示识别动画
   - AI朗读结果：
     ```
     识别结果：

     宫保鸡丁 38元
     鱼香肉丝 32元
     麻婆豆腐 28元
     清蒸鲈鱼 58元
     ```

4. **完成** (2秒)
   - 用户满意
   - 返回首页

**讲解词**：
> "对于简单的文字识别，AI可以直接处理，快速响应用户需求。"

---

### 第四幕：场景描述 → AI直接回答 (1分钟)

**场景**：用户在陌生环境需要了解周围

**操作步骤**：

1. **点击场景描述** (2秒)
   - 点击首页"场景描述"按钮

2. **拍照** (3秒)
   - 展示相机界面
   - 使用预置场景图片

3. **AI描述** (5秒)
   - AI描述场景：
     ```
     场景描述：

     前方2米有一张木桌
     右侧1米有一扇门
     桌上有水杯（注意避让）
     地面平整，可以直行
     ```

4. **完成** (2秒)
   - 用户了解环境
   - 返回首页

**讲解词**：
> "场景描述功能帮助用户感知周围环境，提供导航参考。"

---

### 第五幕：颜色识别 → AI直接回答 (1分钟)

**场景**：用户需要识别衣服颜色

**操作步骤**：

1. **点击颜色识别** (2秒)
   - 点击首页"颜色识别"按钮

2. **拍照** (3秒)
   - 展示相机界面
   - 使用预置衣服图片

3. **AI识别** (5秒)
   - AI识别颜色：
     ```
     这件衣服是深蓝色

     相近颜色：
     • 藏青色
     • 海军蓝

     搭配建议：
     适合搭配白色或浅灰色裤子
     ```

4. **完成** (2秒)
   - 用户满意
   - 返回首页

**讲解词**：
> "颜色识别不仅告诉用户颜色，还提供搭配建议。"

---

### 第六幕：SOS紧急求助 (1分钟)

**场景**：用户遇到紧急情况

**操作步骤**：

1. **触发SOS** (3秒)
   - 长按或连按电源键3次（模拟）
   - 进入SOS紧急页面

2. **SOS页面** (5秒)
   - 显示红色警告界面
   - 显示倒计时（5秒）
   - 显示"正在联系志愿者和紧急联系人..."
   - 显示取消按钮

3. **紧急匹配** (3秒)
   - 倒计时结束
   - 进入紧急匹配
   - 优先显示最近志愿者

4. **通话** (5秒)
   - 快速匹配成功
   - 进入通话
   - 志愿者：张医生
   - 模拟语音："您好，我是张医生，收到您的紧急求助。您现在安全吗？"

5. **结束** (2秒)
   - 挂断通话
   - 演示结束

**讲解词**：
> "紧急情况可以连按电源键3次触发SOS，系统会同时通知志愿者和紧急联系人，优先匹配最近的志愿者。"

---

### 结尾 (30秒)

**讲解词**：
> "这就是'共感 LinkAble'的核心功能演示。我们用AI处理标准化需求，用真人志愿者传递温度。科技助残，让每个人都能平等地享受数字生活。谢谢！"

## 风险预案

### 技术风险

| 风险 | 应对措施 |
|------|----------|
| 应用崩溃 | 准备备用设备，提前录屏 |
| 语音播报失败 | 手动播报内容 |
| 界面卡顿 | 提前清理内存，重启应用 |
| 触摸无响应 | 使用备用设备 |

### 演示风险

| 风险 | 应对措施 |
|------|----------|
| 时间超时 | 准备精简版（跳过部分场景） |
| 评委提问 | 准备技术细节说明 |
| 设备故障 | 准备录播视频备用 |
