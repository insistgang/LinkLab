## 详细操作步骤

### 场景1: 药品识别（核心场景）

**目标**: 展示完整流程：AI识别 → 转人工 → 匹配 → 通话 → 评价

**操作步骤**:

| 步骤 | 操作 | 预期结果 | 时间 |
|------|------|----------|------|
| 1 | 点击"语音求助"大按钮 | 进入AI对话界面 | 2s |
| 2 | 等待AI问候 | 听到"您好！我是您的智能助手..." | 3s |
| 3 | 说"帮我看一下这个药" | AI回复识别结果 | 5s |
| 4 | 说"我想让志愿者确认" | 进入匹配页面 | 3s |
| 5 | 等待匹配动画 | 显示志愿者"小李" | 3s |
| 6 | 等待自动接听 | 进入通话界面 | 2s |
| 7 | 模拟对话 | 听到志愿者语音 | 10s |
| 8 | 点击挂断 | 进入评价页面 | 2s |
| 9 | 选择5星+标签 | 提交成功 | 3s |

**讲解要点**:
- 强调AI识别能力（药品名称、用法用量）
- 强调转人工的安全考虑（重要决策人工确认）
- 介绍志愿者等级系统（灯塔=资深，星辰=专业）
- 提及距离显示（1.2km，就近匹配）

## 应急预案

### 应用崩溃 → 使用备用设备

**应对流程**:
```
1. 立即向评委说明："抱歉，遇到技术小故障，我切换到备用设备"
2. 迅速取出备用设备（已提前准备好）
3. 继续从断点演示，或简要说明后跳到下一环节
4. 如备用设备也无法使用，展示录屏视频
5. 同时口头讲解产品功能，保持演示连贯性
```

**备用方案准备**:
- [ ] 备用手机已安装最新版App
- [ ] 录屏视频保存在相册/云端
- [ ] 准备纸质功能介绍（最后手段）

---

### 语音失败 → 手动播报

**应对流程**:
```
1. 发现语音无响应，等待3秒确认
2. 手动播报AI应回复的内容：
   - "正常情况下，这里AI会播报：'这是阿司匹林肠溶片，100mg，每日一次'"
3. 继续下一步操作，不要停顿太久
4. 演示结束后检查设备音量设置
```

**常用语音内容备用**:
- AI问候: "您好！我是您的智能助手，请问需要什么帮助？"
- 药品识别: "这是阿司匹林肠溶片，100mg，每日一次"
- 菜单识别: "宫保鸡丁38元，鱼香肉丝32元"

---

### 时间不够 → 跳过后续场景

**判断标准**:
- 剩余时间 < 2分钟：启用极速版策略
- 剩余时间 < 1分钟：直接跳至结尾

**应对策略**:

**策略A - 跳过中间场景**:
```
只演示: 开场 → 药品识别 → SOS → 结尾
跳过: 菜单识别、详细功能介绍
说明: "由于时间关系，我重点展示核心功能"
```

**策略B - 加速演示**:
```
- 减少等待时间，快速点击
- 跳过非关键步骤的详细讲解
- 合并多个功能点一起介绍
```

**策略C - 直接结尾**:
```
说: "由于时间关系，我快速总结一下..."
- 重申产品核心价值
- 感谢评委聆听
- 准备进入问答环节
```

## 评委问答参考

### 10个常见问题及回答

**Q1: 这是真实功能还是演示？**
> A: 这是功能演示版本，使用模拟数据展示完整流程。真实版本会连接AI服务（如GPT-4V视觉识别）和志愿者平台，所有功能均可实际运行。

**Q2: 志愿者是真实的吗？如何保障服务质量？**
> A: 演示中是模拟志愿者。真实产品会有严格的志愿者准入机制：实名认证、培训考核、等级评定（灯塔/星辰/微光）。我们有双向评价系统，低分志愿者会被淘汰，确保服务质量。

**Q3: 如何保障用户安全？**
> A: 我们有多重安全保障：①志愿者实名认证+背景审查 ②通话全程录音可追溯 ③双向评价机制 ④敏感操作人工确认 ⑤SOS紧急求助优先匹配专业志愿者并通知紧急联系人。

**Q4: 商业模式是什么？如何盈利？**
> A: 产品以公益性质为主，采用"公益+可持续"的混合模式：①企业CSR合作（员工志愿服务）②政府残联/民政部门补贴支持 ③增值服务（如企业定制版、数据分析服务）。

**Q5: 与现有产品（如Be My Eyes）相比有什么优势？**
> A: 我们的差异化优势：①AI+人工双轨制，80%简单需求AI即时响应，20%复杂需求人工服务 ②本土化优化，针对中国视障群体使用习惯设计 ③志愿者等级体系，专业问题匹配专业人士 ④SOS紧急求助功能。

**Q6: 技术实现上有什么难点？**
> A: 主要技术难点：①AI视觉识别的准确率和响应速度优化 ②志愿者匹配的实时性和精准度（距离、专业、等级多维度）③弱网环境下的稳定性保障 ④无障碍交互设计的细节打磨。

**Q7: 目标用户规模有多大？**
> A: 中国视障人士约1700万，其中智能手机使用率逐年提升。我们的目标是在首年覆盖10万用户，三年内覆盖100万视障人士及其家属。

**Q8: 如何获取用户？推广渠道是什么？**
> A: 多渠道推广：①与残联、盲协合作线下推广 ②视障人士社群/KOL推荐 ③与手机厂商合作预装 ④医院眼科/康复中心合作 ⑤志愿者带动（每位志愿者可能接触多位视障人士）。

**Q9: 数据隐私如何保护？**
> A: 我们严格遵守数据保护法规：①用户数据加密存储 ②通话内容仅用于服务质量监督 ③图像识别数据匿名化处理 ④用户可随时删除个人数据 ⑤通过等保三级认证。

**Q10: 未来发展规划是什么？**
> A: 短期：完善核心功能，扩大志愿者网络，验证产品价值。中期：拓展智能硬件（如智能眼镜）联动，增加更多AI能力。长期：构建视障人士服务生态，连接更多社会资源，成为视障人士的"数字导盲犬"。

## 演示技巧

### 语速建议

| 场景 | 语速要求 | 具体说明 |
|------|----------|----------|
| 开场介绍 | 中等语速 | 清晰有力，建立自信形象 |
| 功能讲解 | 比平时稍慢 | 确保后排评委能听清每个词 |
| 操作演示 | 配合动作 | 操作时说"我现在点击..."，动作与语言同步 |
| 关键亮点 | 放慢+重音 | 如"这是**AI+人工双保障**"，强调关键词 |
| 结尾总结 | 中等语速 | 流畅自然，展现从容 |

**停顿技巧**:
- 关键操作后停顿2秒，让评委看清屏幕
- 重要功能介绍后停顿1秒，给评委消化时间
- 段落之间停顿，区分不同内容模块

---

### 眼神交流

| 时机 | 眼神动作 | 目的 |
|------|----------|------|
| 开场 | 环视所有评委 | 建立连接，展现自信 |
| 功能介绍 | 与中间评委眼神交流2-3秒 | 保持互动感 |
| 关键亮点 | 抬头看评委，强调重点 | 增强说服力 |
| 操作演示 | 偶尔抬头，大部分时间看设备 | 确保操作准确 |
| 结尾致谢 | 环视所有评委，微笑 | 留下良好印象 |

**注意事项**:
- 不要全程低头看设备
- 不要只盯着一位评委
- 眼神自然，不要刻意扫视

---

### 手势建议

| 场景 | 手势动作 | 说明 |
|------|----------|------|
| 指向屏幕 | 使用食指，动作明显 | 手指伸直，指向具体位置 |
| 点击操作 | 稍微用力，有反馈感 | 让评委看到"按下"的动作 |
| 滑动操作 | 平滑移动，速度适中 | 不要过快，确保评委跟上 |
| 强调重点 | 配合语言做手势 | 如"两大核心功能"时竖起两根手指 |
| 展示手机 | 屏幕朝向评委，稍微倾斜 | 确保评委能看到屏幕内容 |

**手势禁忌**:
- 不要用手掌遮挡屏幕
- 动作不要过大或过小
- 避免多余的小动作（如摸头发、玩衣角）

---

### 其他技巧

**音量控制**:
- 确保后排评委能听清
- 在演示场地提前测试音量
- 重要内容适当提高音量

**姿态站姿**:
- 站姿挺拔，展现自信
- 适当移动，不要僵在原地
- 手机拿稳，避免晃动

**应急表情**:
- 出现问题时保持微笑
- 不要皱眉或表现出慌乱
- 用自然的语言化解尴尬
