```text

```

当前文档中不写学校、学院、导师。最终导出前只需要替换：

```text
<团队名称>
<项目名称>
```

建议项目名：

```text

```

## 后续补强优先级

1. 补一组真实或半真实 inference 评测数据：意图识别、紧急判断、转人工决策、响应时延。
2. 录制 5 分钟项目视频，按脚本展示 AI 问答、转人工、通话、SOS、无障碍偏好。
3. 将代码、APK、测试截图、系统架构图、评测表打包为 `其他.zip`。
4. 导出简介和项目文档为 PDF，提交前跑匿名化检查。
