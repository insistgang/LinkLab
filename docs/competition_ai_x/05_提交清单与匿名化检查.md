# 提交清单与匿名化检查

## 1. 官网提交材料

| 材料 | 格式 | 大小/时长 | 当前源文件 |
|---|---|---|---|
| 参赛作品简介 | PDF | 300 字以内 | `01_参赛作品简介_300字.md` |
| 项目文档 | PDF | 按模板 | `02_项目文档_赛题三_AI+X.md` |
| 项目视频 | MP4 | <= 5 分钟，<= 200M | `03_项目视频脚本_5分钟.md` |
| 其他辅助材料 | ZIP | <= 200M | 代码、APK、测试日志、指标表、架构图 |

## 2. 文件命名

```text
<团队名称>_共感LinkAble_参赛作品简介.pdf
<团队名称>_共感LinkAble_项目文档.pdf
<团队名称>_共感LinkAble_项目视频.mp4
<团队名称>_共感LinkAble_其他.zip
```

注意：团队名称应使用报名系统中的团队名称，不要包含学校、学院、导师姓名。

## 3. 匿名化检查

提交前全文搜索并删除或遮挡：

- 学校名称
- 学院名称
- 导师姓名
- 指导教师信息
- 队员姓名以外的身份线索
- 校徽、学院标识、校园地标
- 真实手机号、邮箱、精确地址
- 代码路径中可能暴露学校或个人姓名的内容

建议搜索关键词：

```text
大学
学院
导师
指导教师
具体学校名称
手机号
身份证
地址
本机用户名
本机项目路径
```

## 6. 视频检查

- [ ] 不超过 5 分钟
- [ ] 文件小于 200M
- [ ] 开头 20 秒说清楚项目定位
- [ ] 展示 AI 第一响应
- [ ] 展示转人工匹配
- [ ] 展示 Demo Call
- [ ] 展示 SOS
- [ ] 展示指标或架构，不只展示 UI
- [ ] 不出现学校、学院、导师、真实个人信息

## 7. 最终建议

主叙事不要写成“一个无障碍 App”，而要写成：

```text
AI+无障碍民生服务场景下的第一响应与协同调度系统。
```

答辩时重点强调：

1. AI 不是普通聊天，而是意图识别、风险分流和服务调度。
2. 真人志愿者不是可选装饰，而是复杂和高风险需求的安全兜底。
3. Demo-first 架构保证比赛现场可复现。
4. 无障碍不是 UI 美化，而是全链路硬约束。
